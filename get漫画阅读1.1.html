漫画阅读器使用说明

📚 快速开始

方法一：使用现代浏览器直接打开（推荐）

  1. 使用 Chrome、Edge 或 Opera 浏览器
  2. 直接双击打开 get漫画阅读.html 文件
  3. 点击"选择文件夹"按钮
  4. 在弹出的对话框中选择包含漫画章节的文件夹
  5. 阅读器会自动扫描并加载所有漫画章节

方法二：通过URL参数指定路径

  1. 将HTML文件和漫画文件夹放在同一目录下
  2. 在浏览器中打开：
    file:///C:/Users/steam/Desktop/漫画/一人之下漫画/get漫画阅读.html?comicPath=./一人之下漫画
  3. 或使用相对路径：
    file:///路径/到/get漫画阅读.html?comicPath=./漫画文件夹

方法三：本地服务器（可选）

  1. 在漫画目录中启动本地服务器：
    python -m http.server 8000
  2. 访问 http://localhost:8000/一人之下漫画/get漫画阅读.html

🖱️ 基本操作

  • 翻页：点击左右导航按钮、使用方向键或空格键
  • 缩放：使用工具栏的缩放按钮或Ctrl+滚轮
  • 拖拽：放大后可以拖拽图片查看细节
  • 全屏：点击全屏按钮或按F11键
  • 目录：点击目录按钮查看所有章节

⌨️ 键盘快捷键

  • ← / ↑：上一页
  • → / ↓ / 空格：下一页
  • PageUp：上一章
  • PageDown：下一章
  • Home：跳转到第一页
  • End：跳转到最后一页
  • Esc：关闭目录/面板
  • F11：切换全屏
  • Ctrl + +：放大
  • Ctrl + -：缩小
  • Ctrl + 0：重置缩放
  • H：显示快捷键帮助
  • R：切换自动翻页

📱 移动端操作

  • 滑动翻页：左右滑动屏幕切换页面
  • 双指缩放：双指捏合缩放图片
  • 点击切换工具栏：点击屏幕中间切换工具栏显示

⚙️ 阅读模式

  • 翻页模式：单页显示，适合精细阅读
  • 连续模式：所有页面连续显示，适合快速浏览
  • 自动翻页：设置翻页间隔自动阅读
  • 自动滚动：连续模式下自动滚动阅读

📖 文件结构要求

漫画文件夹应按照以下结构组织：

漫画文件夹/
├── 章节1/
│ ├── 001.jpg
│ ├── 002.jpg
│ └── ...
├── 章节2/
│ ├── 001.jpg
│ └── ...
└── ...

支持格式： JPG, JPEG, PNG, WebP

🔧 浏览器兼容性

  • 推荐浏览器： Chrome, Edge, Opera
  • 文件选择： 仅支持File System Access API的浏览器
  • 备选方案： 通过URL参数或本地服务器加载

💾 数据保存

  • 阅读进度： 自动保存当前章节和页码
  • 书签： 支持导出和恢复阅读位置
  • 设置： 阅读偏好设置自动保存
